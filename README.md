## About This Repository

This repository documents my journey into **Embedded C Programming and Microcontroller Development**.

I have completed the course **Microcontroller Embedded C Programming: Absolute Beginner** by Kiran Nayak (FastBit Embedded Brain Academy).

Now, I'm moving beyond simply following tutorials. My focus is on strengthening my programming fundamentals through daily problem-solving, practical exercises, debugging, and hands-on experimentation.

Every problem I solve is an opportunity to improve my understanding of C, memory, processors, and hardware-level programming.

**My philosophy: Understand the concept. Solve the problem. Write the code yourself.**

## Learning Roadmap

My learning journey is organized into the following areas:

### 1. Embedded C Fundamentals
- C data types and variables
- Operators and expressions
- Control statements and loops
- Functions and modular programming
- Arrays and pointers
- Structures and unions
- Storage classes
- Preprocessor directives

### 2. Bit Manipulation
- Binary and hexadecimal representations
- Bitwise AND, OR, XOR and NOT
- Bit masking
- Setting, clearing, toggling and testing bits
- Bit extraction techniques
- Bit fields

### 3. Memory and Embedded Concepts
- Pointers and memory addresses
- Code memory and data memory
- Stack and memory layout
- `const` and `volatile` qualifiers
- Memory-mapped I/O
- Peripheral register access

### 4. Microcontroller Programming
- Microcontroller architecture
- Processor and peripheral concepts
- GPIO configuration
- Register-level programming
- Structures for peripheral registers
- Hardware interfacing fundamentals

### 5. Build and Debugging
- Preprocessing, compilation and linking
- GCC compiler
- ELF executable analysis
- Disassembly
- GNU utilities (`objdump`, `size`)
- Compiler optimization levels
- Debugging and code analysis

*This roadmap includes both completed course concepts and areas I intend to strengthen through practice.*

## Daily Problem-Solving Challenges

One of the main objectives of this repository is to develop independent problem-solving skills.

I follow a daily challenge routine where I receive practical programming problems based on my current knowledge.

Each challenge is designed to:

- Strengthen programming logic.
- Improve problem-solving ability.
- Reinforce previously learned concepts.
- Introduce combinations of multiple concepts.
- Develop embedded programming thinking.
- Encourage clean, structured and maintainable code.

### Challenge Rules

1. I attempt every problem independently.
2. I do not copy solutions from other sources.
3. I focus on understanding the logic before implementation.
4. I debug and test my own implementation.
5. I document and commit my progress using Git.

**The objective is not just to make the program work, but to understand why it works.**
